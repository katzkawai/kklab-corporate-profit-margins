# 日本の業種別売上高経常利益率 可視化プロジェクト — 設計書

日付: 2026-09-22
ステータス: 承認済み（ユーザー確認済み）

## 目的

日本の主要業種（製造業5業種＋非製造業5業種）の「売上高経常利益率」を比較・可視化し、
ビジネスモデル上の要因の解説とともに GitHub Pages で公開する。

## 成果物

```
kklab-corporate-profit-margins/
├── README.md                  # GitHub Pages トップ: 解説・分析・画像・出典
├── plot_profit_margins.py     # 描画スクリプト（データはコード内に埋め込み）
├── requirements.txt           # matplotlib, japanize-matplotlib
├── images/
│   ├── profit_margin_ranking.png   # 最新年度 降順ランキング棒グラフ
│   └── profit_margin_heatmap.png   # 直近3年度 業種×年度ヒートマップ
└── .gitignore
```

## データ

- ソース: 財務省・財務総合政策研究所「法人企業統計調査」年度別調査（確定決算ベース）の公表値
- 指標: 売上高経常利益率（%）＝ 経常利益 ÷ 売上高 × 100
- 対象年度: 直近3年度（FY2022・FY2023・FY2024）。FY2024年次分は2025-09-01に公表済み
- 対象業種（全10業種）:
  - 製造業: 輸送用機械器具（自動車）、電気機械器具、情報通信機械（電子部品・デバイス）、化学、食料品、鉄鋼 から選定
  - 非製造業: 情報通信業、卸売業、小売業、運輸業、サービス業、不動産業・物品賃貸業 から選定
  - 最終的な10業種は実装時に公表データの確認結果に基づき確定し、製造5＋非製造5のバランスを守る
- 確認済みアンカー値（実装時に一次情報で照合する）:
  - FY2024: 全産業 6.8%、製造業平均 8.6%、不動産業 13.6%（非製造業で最高）、建設業 5.4%
  - FY2023（製造業内訳例）: 化学 12.1%、電気機械 8.8%、鉄鋼 7.0%、情報通信機械 6.6%、食料品 4.7%
- 出典は README に明記。コード内データには年度・出典をコメントで併記する
- 照合できないセルがあった場合は四半期データの年度平均から推計し、「推計値」と明記する

## スクリプト仕様（plot_profit_margins.py）

- 依存: Python 3.10+、pandas、matplotlib、japanize-matplotlib
- データ構造: `{業種名: {"sector": "製造業"|"非製造業", "values": {"2022年度": x, "2023年度": y, "2024年度": z}}}` 形式の辞書
- グラフ1（ランキング棒グラフ）:
  - 最新年度（FY2024）の値で降順ソートした横棒グラフ
  - 製造業／非製造業で色分け＋凡例、各バーに数値ラベル
  - `images/profit_margin_ranking.png` に保存（150dpi）
- グラフ2（ヒートマップ）:
  - 行=業種（FY2024降順）、列=年度（FY2022–FY2024）
  - `imshow` ベース、カラーバー付き、各セルに数値注記（小数1桁）
  - `images/profit_margin_heatmap.png` に保存（150dpi）
- 日本語フォント: `import japanize_matplotlib` を冒頭で行い文字化け対策。未導入環境向けに requirements.txt に明記
- 実行: `python plot_profit_margins.py` で images/ を生成して終了（CLI引数なし）

## README.md（GitHub Pages コンテンツ）

構成:
1. 概要とグラフ2点（画像埋め込み）
2. データの出典・定義（売上高経常利益率の計算式、年度、調査の性質）
3. 分析解説:
   - 不動産業が高い理由: 賃貸収入の安定性、在庫リスク薄、高粗利構造
   - 情報通信業が高い理由: ソフトウェア・無形資産中心、限界費用の低さ、スケールメリット
   - 化学・電機が比較的高い理由: 付加価値の高い機能材・部品、近年の価格転嫁
   - 卸売・小売が低い理由: 薄利多売モデル、売上総利益率の低さ、価格競争
   - 鉄鋼・一次素材が低めの理由: 商品市況連動、重い設備投資・エネルギーコスト
   - 運輸業が低めの理由: 労働集約・燃料費、価格転嫁の遅れ
4. 再現方法（セットアップと実行手順）
